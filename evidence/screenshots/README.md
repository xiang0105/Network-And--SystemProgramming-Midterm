# Execution Screenshots

本目錄保存正式報告使用的執行畫面。畫面只顯示本專案與 loopback 測試結果，不包含密碼、token、使用者名稱或私人路徑。

| 檔案 | 證據內容 |
| --- | --- |
| `01-ctest-6-of-6.png` | 六組 CTest 全數通過 |
| `02-ten-client-concurrency.png` | 同一 server parent 下 10 個同時存在的 child processes |
| `03-robustness-comparison.png` | 三組未改善與已改善行為對照 |
| `04-packet-frame-analysis.png` | `tcpdump -X` 顯示 `ABGM` header 與 TCP close |
| `05-client-system-info.png` | Client 選單、server system information 與 connection stats |
